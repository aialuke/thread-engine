🧵 Here are the 6 settings that fixed it:

---

<!-- card 1: title / default / path / action / payoff -->
**Wi-Fi Channel Selection**
Auto on install day. Neighbours pile onto it for years.
Admin (`192.168.1.1` or `192.168.0.1`) → Wireless Settings → Channel.
Off Auto. Set 2.4GHz to 1, 6, or 11.
Evening buffering drops in minutes.

<!-- card 2 -->
**5GHz vs 2.4GHz Band Priority**
TV and Zoom laptop stuck on the first band they saw. Fast 5GHz sat empty.
Wireless Settings → rename 5GHz so it is not the same SSID as 2.4.
Reconnect the streamers and the call laptop to 5GHz.
Call and 4K sit on the fast band.

<!-- card 3 -->
**QoS**
A phone update equals a Zoom call.
Advanced Settings → QoS. On. Tag video high if the menu allows.
The call holds while someone else downloads.

<!-- card 4 -->
**Firmware Update**
Routers sit years without a patch.
Administration / System → Firmware Update. Check. Install. Reboot.
Random disconnects stop.

<!-- card 5 -->
**DNS Server Change**
Every lookup uses ISP DNS.
WAN / Wireless → DNS Server. Public resolver the docs name (`1.1.1.1` or `8.8.8.8`).
Pages start on every device.

<!-- card 6 -->
**Connected Devices Cleanup**
Old phones still listed. Gold residue: 11 ghosts, gone more than a year.
Connected Devices / Attached Devices. Forget anything not in the house.
Reserved slots free up.

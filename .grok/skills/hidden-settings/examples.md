## A) Router QoS — Comcast/Xfinity style, 8 settings

Money villain: the extra speed tier.

**Hook**
1. Result — same gateway, the evening calls hold on the plan they already pay for
2. Neglect — gateway plugged in on install day, admin never opened again
3. Scene — family, evening Zoom freeze, 4K buffering, about to buy the next speed tier
4. Expert — IT-guy, ten minutes in the admin page
5. – Didn't buy the upgrade. – Didn't buy a new gateway. – Didn't call Comcast.
6. Snap — 8 settings. Same gateway, same plan, different house
7. Quote — the speed tier was never the problem; technician setup was still running
8. 🧵 Here are the 8 settings that fixed it:

**Cards**
1. Wi-Fi channel — Auto on install day — admin (often `10.0.0.1`) → Wireless → Channel — set 2.4 to 1/6/11, pick a clear 5GHz — evening buffering drops
2. Split the bands — one SSID, devices stick — Wireless → 2.4/5 names — rename 5GHz; put TV and Zoom laptop on it — call and 4K sit on the fast band
3. QoS — a phone update equals a Zoom call — Advanced → QoS — on; tag video high if the menu allows — the call holds during a download
4. Firmware — years without an update — Administration → Firmware Update — check, install, reboot — random disconnects stop
5. DNS — ISP DNS on every lookup — WAN → DNS — public resolver the docs name (`1.1.1.1` or `8.8.8.8`) — pages start
6. Forget ghost devices — old phones still listed — Connected Devices — forget anything not in the house — gold residue: 11 ghosts
7. Smart Connect / band steering — gateway picks the congested band — Wireless → Smart Connect — off once names are split — Zoom laptop stays on 5GHz
8. Park IoT on 2.4 — bulbs and doorbells share the call's lane — 2.4 SSID + device list — IoT on 2.4, people on 5GHz — doorbell upload leaves Zoom alone

**Closer**
✓ Channel. Split bands. QoS. Firmware. DNS. Ghost devices. Band steering. IoT on 2.4.
Same gateway. Same plan. Different evenings.
Ten minutes. No speed-tier upgrade.
Reply with the gateway model (xFi, XB7, XB8, sticker name) and which of the 8 the menu has.

## B) iPhone Camera — 7 settings

Money villain: a photography course, or a new phone for the camera.

Shipped gold: `examples/iphone-camera-7-settings/` (conversation `2101926639198441689`) — wedding guest, $1,200 body, same seven cards.

**Hook**
1. Result — same iPhone, the reception photo comes out straight
2. Neglect — Camera left on day-one defaults
3. Scene — wedding guest, reception photos flat / crooked / wide, about to buy a course or a new phone
4. Expert — photographer at the next table, four minutes
5. – Didn't install an app. – Didn't edit anything. – Didn't switch to Portrait mode.
6. Snap — 7 settings. Same phone, same seat, same photo
7. Quote — the camera was never the problem; training wheels still on
8. 🧵 Here are the 7 settings that fixed it:

**Cards**
1. Grid and Level — blank viewfinder, horizon off — Settings → Camera → Grid, Level — face on a line; wait for yellow — the table shot looks chosen
2. AE/AF Lock — tap once, phone keeps guessing — tap and hold until AE/AF LOCK — lock, then slide exposure — face stays sharp
3. Photographic Styles — Standard, flat — Camera → Styles (or Settings → Camera → Photographic Styles) — pick one, leave it — colour decided while shooting
4. Resolution — lower MP to save storage — Settings → Camera → Formats → Photo Mode 24MP — 24MP daily; 48MP to crop — skip if no 24/48 toggle
5. Default focal length — Pro opens ~24mm, faces stretch — Settings → Camera → Main Camera (or Fusion Camera) → 28mm or 35mm — set default; step forward instead of 0.5x — skip if no Main Camera menu
6. Volume button shutter — on-screen shutter shoves the phone — volume up is shutter — index finger on the button, elbows in — one frame nobody blinks
7. Preserve Settings — close Camera, factory setup returns — Settings → Camera → Preserve Settings — on last, so 1–6 stick — camera opens the way you left it

**Closer**
✓ Grid + Level. AE/AF Lock. Photographic Style. Resolution. 28/35mm default. Volume shutter. Preserve Settings.
Same phone. Same lens. Same wedding. Different photos.
Four minutes. No course. No new phone.
Reply with the model — 13, 15, 16 Pro, 17 — and which of these 7 exist on it.

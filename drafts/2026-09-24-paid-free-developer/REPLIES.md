# REPLIES: talking points for PAID → FREE developer

These are points for replies under the post, not text to paste. Write each reply in your own words, in one or two sentences, and answer only the row the person raised. Never edit the post to add a caveat. Sources are in `CLAIMS.md`.

- **"Postman is free."** It is, for one person. Team, at $19 a user a month, is what you pay to share collections. With Bruno the collections are files in the repo, so they're shared the way the code is.
- **"Bruno's Git features are paid."** The Git buttons inside the app are (Pro, $6 a user a month). The collections are plain-text files in the repo, so ordinary Git works on them without those buttons.
- **"Bruno's free plan has limits."** Yes: 5 OpenAPI syncs a month, and run reports are paid. Sending requests, tests and scripting are all on the free plan.
- **"Beekeeper doesn't do Oracle / MongoDB / Snowflake."** Not on the free edition. Those start at the paid tiers. The free one covers Postgres, MySQL, SQLite, SQL Server and a long list of others.
- **"Is Beekeeper free at work?"** The code is GPLv3. Beekeeper's pricing page says the free edition is meant for individuals and small teams, and the README asks people using it at work to buy a licence. Say it's their request. Don't call it a licence term.
- **"Navicat has a free version."** Navicat Premium Lite is free, with core features and up to 5 users per organisation. The row is about the full Premium licence.
- **"Cloudflare Tunnel needs a domain."** Right. You add a domain to Cloudflare first, and the tunnel itself is free on every plan. Without a domain, Quick Tunnels give a random trycloudflare.com address with no account, but Cloudflare says those are for testing only.
- **"ngrok's free plan gives you a domain."** It gives you one assigned dev domain, with a warning page in front. Your own domain starts at Pay-as-you-go ($20 a month plus usage). Hobbyist ($10) removes the warning page but still uses ngrok's domains.
- **"Why not Podman instead of Docker Desktop?"** Docker Desktop is free for personal use and for companies under 250 staff and $10M revenue, so for most people it isn't a paid swap. Podman Desktop is free and open source if someone asks for it.
- **Someone suggests another tool.** Thank them, and say it gets checked on its own site before it's ever listed. Don't vouch for features nobody has checked.

Setting 6: HDMI enhanced

This card is only for a box on HDMI. Apple TV, Fetch, Foxtel, a stick. Netflix / YouTube / ABC iView inside the TV apps do not use it. No box? Skip it.

The port often ships in Standard. HDR from the box never arrives. The film looks flat. People blame the TV.

Samsung: All Settings → General & Privacy → External Device Manager → Input Signal Plus → the HDMI port you actually use → On. Older menus say HDMI UHD Color. The screen may flicker when you toggle it.

Sony: Settings → Channels & Inputs → External inputs → HDMI signal format → Enhanced format. 4K120 / VRR only on the labelled ports. Picture or sound dies? Drop that port back to Standard.

LG: All Settings → Picture → Additional Settings → HDMI Ultra HD Deep Color → On for the 4K box. Off if the box is HD-or-lower.

Hisense: no official HDMI-format path this session. Skip.

One action: turn Enhanced / Input Signal Plus / Ultra HD Deep Color on for that one port. Same film, from the box, with the HDR the file already had.

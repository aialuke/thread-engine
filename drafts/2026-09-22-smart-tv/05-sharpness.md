Setting 4: Sharpness down

Default sharpness draws a halo around credits and faces. The TV is inventing edges the file did not have.

Samsung: All Settings → Picture → Expert Settings → Sharpness.

LG: All Settings → Picture (Picture Mode Settings) → Sharpness.

Sony: Settings → Display & Sound → Picture → Clarity.

Hisense VIDAA: Settings → Picture → Picture Mode Settings → Sharpness.

Turn it down until the ringing on titles and cheekbones is gone. Leave it.

Already in FILMMAKER MODE? Skip this card. That mode already kills sharpening.

No Sharpness / Clarity slider? Skip it.

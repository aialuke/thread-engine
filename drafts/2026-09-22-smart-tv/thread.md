# smart-tv

---

A Sunday film on a 4K TV can stop looking like a soap.

Most 4K TVs get set up on delivery day and Picture is never opened again.

Jess was about to spend $3,244 on a 65-inch OLED because a Sunday-night film on Netflix looked like a soap. Her brother, who hangs TVs on weekends, sat on the couch for ten minutes with the remote she already had.

– Didn’t buy a new OLED.
– Didn’t buy a soundbar.
– Didn’t pay for a calibration.

He changed 7 settings. Same TV. Same film. Same seat.

“Your panel was never the problem. The setup-day motion control was still on, the picture mode was still the delivery default, and energy saving was eating the brightness. The film look is already in Settings. Nobody on the box is going to walk you through it.”

🧵 Here are the 7 settings that fixed it:

---

Setting 1: Motion Off

The TV ships with motion processing on Auto. Movies are 24 frames a second. The set invents frames in between. That is the soap-opera effect. Netflix on a Sunday looks like daytime TV.

There is no menu called Motion Smoothing. The label is the brand’s.

Samsung: Settings → Picture → Expert Settings → Auto Motion Plus Settings (some years say Picture Clarity Settings). Default is Auto. Set it to Off.

LG: All Settings → Picture → Advanced Settings → Clarity → TruMotion → Off. (2020 webOS 5.0: Picture Mode Settings → Picture Option → TruMotion.)

Sony: Settings → Display & Sound → Picture → Motion → Motionflow → Off.

Hisense VIDAA: Settings → Picture → Picture Mode Settings → Motion → Ultra Smooth Motion → Off.

One action: Off. Same couch. Same film. Cadence comes back.

Watching sport tonight? Put it back on Auto / Custom. No motion menu? Skip it.

---

Setting 2: Picture mode

Samsung’s official default is Standard. Store floors sit on Dynamic. Both juice the image. Skin goes neon. The film already had a grade.

Samsung: Settings → All Settings → Picture → Picture Mode → FILMMAKER MODE. No Filmmaker row? Movie. Then Expert Settings → Apply Picture Settings → all input sources, so Netflix, YouTube, ABC iView, and HDMI share it.

LG: All Settings → Picture → Select Mode → FILMMAKER MODE. No Filmmaker? Cinema. Picture → Advanced Settings → FILMMAKER MODE Auto Start → On if you want compatible titles to switch themselves.

Sony: Settings → Display & Sound → Picture → Picture mode → Cinema. 2024+ may list Professional. Sony does not use Filmmaker Mode on the official helpguide. Do not hunt for a name that is not there.

Hisense VIDAA: Settings → Picture → Picture Mode → FILMMAKER or Cinema. Intelligent Mode Settings → Content Type Auto Detection will jump to FILMMAKER only when the stream is tagged.

⚠️ Filmmaker / Cinema looks darker than Dynamic. That is the mode working.

No Filmmaker, Movie, or Cinema row? Skip it. Motion Off still applies.

---

Setting 3: Energy saving Off

The film still looks dim after you leave Filmmaker on. People blame the panel. The TV is throttling brightness to save power.

Samsung 2025: Settings → All Settings → General & Privacy → Power and Energy Saving. Turn off Energy Saving Solution, Brightness Optimisation, Motion Lighting.

Samsung 2024: same three toggles, but the door is Settings → All Settings → Support → Device Care → General & Privacy → Power and Energy Saving.

LG 2022–2025: All Settings → General → Energy Saving → Energy Saving Step → Off.

LG 2026 (webOS 26): All Settings → System → Energy Saving → Energy Saving Step → Off.

Sony: Settings → Display & Sound → Picture → Light sensor / Ambient light sensor → Off. Newer firmware also has Eco Dashboard → Power saving.

Hisense VIDAA: do not leave Picture Mode on Energy Saving. Picture Mode Settings → Automatic Light Sensor → Off. Intelligent Mode Settings → AI Energy mode → Off, or it will throw you back into Energy Saving.

Same room. Same film. The blacks hold. The image stops pumping.

No energy / sensor row? Skip it.

---

Setting 4: Sharpness down

Default sharpness draws a halo around credits and faces. The TV is inventing edges the file did not have.

Samsung: All Settings → Picture → Expert Settings → Sharpness.

LG: All Settings → Picture (Picture Mode Settings) → Sharpness.

Sony: Settings → Display & Sound → Picture → Clarity.

Hisense VIDAA: Settings → Picture → Picture Mode Settings → Sharpness.

Turn it down until the ringing on titles and cheekbones is gone. Leave it.

Already in FILMMAKER MODE? Skip this card. That mode already kills sharpening.

No Sharpness / Clarity slider? Skip it.

---

Setting 5: Colour tone Warm

Cool / Standard is the setup-day white. Skin goes blue-grey. The film was graded warmer than that.

Samsung: All Settings → Picture → Expert Settings → Color Tone → Warm2.

LG: Picture → Advanced Settings → Color → Color Temperature → Warm (some years say Warm50). Take the warmest option still labelled Warm.

Sony: Picture → Adv. color temperature. Cinema already aims film. If Cinema looks right, leave it.

Hisense: Picture Mode Settings → Colour / colour temperature → Warm if you have it.

Already in FILMMAKER MODE? Skip this card. Filmmaker is D65. You already have the white point.

No Color Tone / Color Temperature row? Skip it.

---

Setting 6: HDMI enhanced

This card is only for a box on HDMI. Apple TV, Fetch, Foxtel, a stick. Netflix / YouTube / ABC iView inside the TV apps do not use it. No box? Skip it.

The port often ships in Standard. HDR from the box never arrives. The film looks flat. People blame the TV.

Samsung: All Settings → General & Privacy → External Device Manager → Input Signal Plus → the HDMI port you actually use → On. Older menus say HDMI UHD Color. The screen may flicker when you toggle it.

Sony: Settings → Channels & Inputs → External inputs → HDMI signal format → Enhanced format. 4K120 / VRR only on the labelled ports. Picture or sound dies? Drop that port back to Standard.

LG: All Settings → Picture → Additional Settings → HDMI Ultra HD Deep Color → On for the 4K box. Off if the box is HD-or-lower.

Hisense: no official HDMI-format path this session. Skip.

One action: turn Enhanced / Input Signal Plus / Ultra HD Deep Color on for that one port. Same film, from the box, with the HDR the file already had.

---

Setting 7: Viewing information

This one is not the picture. It is the other default from setup day: the TV logging what is on the screen.

Samsung: open the Privacy Choices app, or Settings. Turn off Viewing Information Services. If you also see Customised Ads or Interest-Based Advertising, turn those off too. Cannot find the label? Skip it.

Sony / Hisense Google TV: Settings → Privacy → Ads → Delete advertising ID. Official Google line: you cannot turn ads off. Delete the ID. Ads still appear. They stop using that ID.

LG Live Plus is not on an official support page this session. Do not guess the menu. Skip.

This does not fix the soap opera. Cards 1–5 did that. This stops the set sending viewing signatures after you already opened Settings.

The full pass.

✓ Motion Off. Picture mode. Energy saving Off. Sharpness down. Colour Warm. HDMI enhanced. Viewing information.

Same TV. Same film. Same couch. Different picture.

Ten minutes. No $3,244 OLED.

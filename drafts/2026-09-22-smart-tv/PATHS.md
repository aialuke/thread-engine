## Gated controls

- FILMMAKER MODE: model/region. Thread uses ⚠️ once: it looks darker than Dynamic/Standard. That is the mode working.
- Input Signal Plus / Enhanced HDMI / Ultra HD Deep Color: per HDMI port; 4K120/VRR only on labelled ports.
- TruMotion: hidden in Game Optimizer.
- Samsung energy items: hidden when Adaptive Picture or Game Mode is on.
- Hisense FILMMAKER auto-switch: only when a filmmaker signal is detected.

## UHD Alliance (why Filmmaker Mode)

https://filmmakermode.com/about/ — 2026-09-22 — Motion interpolation Off, sharpening Off, TV noise reduction Off, other enhancement Off, white point D65. Not a Settings path; supports the picture-mode card.

## Conservative conflict rulings

- Motion: **Off**, not Custom / Cinematic Movement / Smooth. Fork those only as a skip (“sport night, put it back”).
- Sony film look: **Cinema**, never Filmmaker Mode.
- Samsung energy: print **2025 path**, then the 2024 Support → Device Care fork.
- LG energy: print **General → Energy Saving** (2022–2025 majority), then the 2026 System fork.
- Samsung HDMI: **General & Privacy → External Device Manager → Input Signal Plus** (2025 user guide), older name HDMI UHD Color.
- Tracking: Samsung **Viewing Information Services via Privacy Choices / Settings**; Google TV **Delete advertising ID**. LG Live Plus stays VERIFY.

# Checklist: tool-swap (PAID → FREE)

- [ ] Root opens with `PAID → FREE` and `Finding free <word> tools that actually hold up.`, word from the skill's table
- [ ] 2 to 5 swaps from one roster category (or a single for OBS, Krita, KeePassXC or Pi-hole), strongest first
- [ ] Each paid side is one named product people on X talk about (checked with `x_read.py search`), and really paid
- [ ] CLAIMS.md rows for every swap: task, free tier, paid side paid, limit, source URL, date; vendor-stated or tested
- [ ] A claim the vendor's page doesn't state is cut unless the operator tested it
- [ ] Offered the operator an optional test (not required)
- [ ] Proof lines positive and true as written, from the sources; no "replaces", feature sheets, changelog wording or roster copy
- [ ] "Free", not "open source", unless CLAIMS.md shows it
- [ ] No @handles, hashtags or 1/5 in the root; at most 600 as X counts (`post_thread.py <folder> --count`)
- [ ] Optional shout-out: one line, one organisation handle checked with `x_api.py user` this session, not reused
- [ ] REPLIES.md: talking points from the limits and free plans, not paste-ready replies
- [ ] Image optional: a real screenshot from the operator's use if there is one; no logos or press images
- [ ] voice/exit-zero.md banned phrases and farm tells cut
- [ ] APPROVED is absent. The operator approves by typing /approve <slug>
